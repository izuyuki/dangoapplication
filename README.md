# DANGO
写真の色・明るさ・コントラストを使って10体の仲間に出会う、スマートフォン対応の静的Webアプリです。

## 使い方
index.htmlをブラウザで開くか、静的サイトとして公開してください。AI、APIキー、ビルド、依存ライブラリは不要です。画像はブラウザ内で処理し、外部へ送信しません。図鑑にはキャラクター番号だけをlocalStorageに保存します。観察写真は保存しません。同じ写真のデコード結果なら同じキャラクターになります。端末・ブラウザを変えると図鑑は共有されません。

## GitHub Pagesへの配置
1. GitHubのリポジトリを作成します。
2. このフォルダの index.html、style.css、app.js、assets フォルダ、.nojekyll をリポジトリ直下へ配置します。
3. Settings → Pages → Deploy from a branch で main と /(root) を選択して保存します。
4. GitHubが表示する公開URLで開きます。画像パスは相対パスなのでサブディレクトリにも対応します。

## 判定仕様・限界
96×96画素へ縮小し、全体の平均輝度、輝度の標準偏差、RGBの最大最小差の平均、赤と青の差を計算します。app.jsのanalyzePixels関数で整数化して組み合わせ、0〜9へ割り当てます。暗い写真から明るい写真まで、10種類すべてに到達できます。乱数や撮影日時は使いません。
これは遊びのための簡易な画像処理です。物体検出はしないため、ダンゴムシ以外の画像でも結果が出ます。背景・照明・構図が変わると同じ個体でも結果が変わります。ファイルの種類・破損などで画像を読み込めない場合は結果を出さず再選択を案内します。上限25MBです。

## 変更方法
キャラクター名・説明・観察ミッションは app.js の characters、画像は assets/0.jpg〜9.jpg にあります。トップは assets/0.jpg（ダンゴマサムネ）。フッターの表記は「テクノダンゴムシ」です。

## 動作確認
画像解析の出力範囲・全10体への到達・同一画素の再現性を確認。実際の屋外写真での出現バランスは今後調整してください。
